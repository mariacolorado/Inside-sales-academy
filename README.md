# Inside Sales Academy - Rappi 🚀

Esta es una plataforma interactiva de e-learning diseñada para el entrenamiento del equipo de ventas. La aplicación utiliza elementos de gamificación para mejorar la experiencia de aprendizaje.

## ✨ Características
- **Gamificación:** Sistema de niveles (Rookie, Silver, Legend) y visualización de RappiPoints.
- **Interfaz Moderna:** Diseño limpio utilizando la fuente Poppins y los colores institucionales.
- **Asistente IA:** Incluye a 'Max', un mentor virtual para guiar a los usuarios.
- **Responsivo:** Optimizado para diferentes tamaños de pantalla.

## 🛠️ Tecnologías utilizadas
- HTML5
- CSS3 (Variables personalizadas, Flexbox)
- JavaScript (Vanilla ES6)

## 🚀 Cómo ver el proyecto
1. Clona este repositorio.
2. Abre el archivo `index.html` en tu navegador.
